## 1. キャンバスと余白
- 4:3、1128×846px。Google スライド / Keynote の 4:3 と同じ比率。PDF も同サイズ（@page 1128px×846px）。
- 左右の余白は 56px。本文の幅は 1016px（56〜1072）。
- 内容スライドは左端に幅 8px のライトグリーン縦帯。右下にページ番号（14px・muted）、左下に「Domuz inc. Confidential」（12px・muted。社内向けなら `Deck(confidential=False)`）。
- タイトルは (56, 44) に 38px 太字。サブタイトルは (56, 100) に 20px・secondary。本文は top 160px から。
- サブタイトルが約50字を超えて2行になるときは本文全体を 36px 下げる（`Deck.slide` が自動でやる）。
- 脚注（※ 出典・注記）は下から 44px に 14px・secondary。
- 1スライドに入る高さは 160〜760px の約600px。収まらないときは文字を小さくせず、スライドを分ける。

## 2. 色（トークン）
| 変数 | 値 | 使いどころ |
|---|---|---|
| `--moss` | #004347 | 本文の文字、主役の棒、塗りのカード、章扉の地 |
| `--light` | #00D79C | 強調（番号・ハイライト・最大値の棒・利益）。1スライドに1〜2か所 |
| `--flower` | #EF667D | 花に関する系列（アンドフラワー）。フローの「花」のタグなど |
| `--secondary` | #626262 | サブタイトル、補足、表の見出し |
| `--strong` | #E16464 | マイナス・警告の数字だけ |
| `--muted` | #999999 | ページ番号、フッター |
| `--bg-gray` / `--bg-gray2` | #CBD0D3 / #9DA6A9 | 比較対象（前年・原価・実費）の地味な棒 |
| `--bg-tint` | #F3F6F6 | 図の背景、tint カード |
| `--border` | #C9CFCF | 罫線（1px） |
| `--watermark` | #ECEEEE | 表紙の透かし |

原則: 面で色を使うのは Moss と Light の2色＋灰色。赤（strong）は「悪い数字」にしか使わない。

## 3. 文字
- 英数字は Outfit、和文は Zen Kaku Gothic New（Google Fonts）。CSS の font-family の順でそう振り分けられる。
- 数字を見せる要素は `.en` を付けて Outfit に固定し、表の数値列は tabular-nums。
- サイズの目安: 表紙タイトル 52 / 章扉 46 / スライドタイトル 38 / 見出し(h3) 24〜26 / 本文 18〜20 / 表 15〜18 / 脚注 14 / キーメッセージ 24〜28 太字 / KPI 72。
- 強調は `[[語]]`（ライトグリーン太字）と `**語**`（太字）の2種類だけ。色を増やさない。
- 丸数字①②③は使わない（Web フォントにないので代替フォントになる）。`<span class="circ">1</span>` を使う。

## 4. スライド型
| 型 | メソッド | 使う場面 |
|---|---|---|
| P-1 表紙 | `cover()` | 透かし「Domuz」3段＋左寄せタイトル。宛名（to）は外部向けのときだけ |
| P-2 主張文 | `message()` | 白地の中央に1〜2行。章の切り替え、いちばん言いたいこと |
| P-3 章扉 | `divider()` | Moss 全面、アウトライン数字 01/02/03、英字ラベル（ALL CAPS・letter-spacing 6px）、和文タイトル。3章以上あるときに入れる |
| P-6 主要数字 | `kpi()` | 左に数字（72px）、右にグラフや表 |
| P-11 番号付きリスト | `nlist()` | アジェンダ、論点、3つの理由。番号はライトグリーン 64px |
| 内容スライド | `slide()` | 上の部品を `.body` の中で組み合わせる |

## 5. 部品の使い分け
- **cards**: 並列の3項目（メリット・理由）。枠線カードが基本。塗り（fill）は1枚だけ主役にしたいとき、tint は補助情報。
- **table**: 行が8行以内。右寄せの数値列、`strong_col` で結論の列だけライトグリーン。ステータスは `pill()`（done=塗り / plan=枠 / todo=灰）。1列目の折り返しが気になるときは `white-space:nowrap`。
- **hbar**: 内訳・構造（価格のうち何が原価で何が利益か）。複数の棒を同じ scale で描く。利益は Light、原価は灰、相手側の取り分は白＋Moss 枠。
- **vbars**: 時系列。最大値だけ Light。
- **photo_grid**: 商品ラインナップ（写真＋名前＋価格＋一言）。写真は object-fit: cover で縦横をそろえる。
- **フロー図**: `node()`（丸＋アイコン＋ラベル。自社は Moss 塗り、相手は白）、`arrow()`、`tag()`（矢印に「何が動くか」）。横矢印のタグは矢印の上（y−38）に置くとノードと重ならない。図は `background: var(--bg-tint)` の帯の中に置き、1列 320px で3つ横並びまで。

## 6. 図版
- 写真は JPEG 品質 85〜88、長辺 1200px 程度に縮小してから `img()` で base64 埋め込み（HTML を1ファイルで渡せる）。
- 外部資料の図（配送フロー等）はそのまま貼らず、SVG で Domuz 配色に描き直す。写真の集合画像は写真だけ切り出して並べ直す。
- 線画アイコンは `scripts/trim_icon.py` で余白を切り Moss/白/灰の3色にする。同梱は box / warehouse / bouquet / person。
- 図面（倉庫など）は画像の上に半透明の矩形（Moss .45 / Light .40 / Flower .18）を重ねて区画を示し、右に凡例を付ける。
- スクリーンショットは必要な部分だけ切り出し、1px の `--border` で囲む。

## 7. 文言のルール
- 元資料の文言・数値は変えない。言い換えは見出しだけ（例: 「BtoBで進める理由」→「イネイブラーのメリット」は依頼があったときのみ）。
- 期は「26年9月期」のように YY年9月期、ブランド名はカタカナ（アンドプランツ／アンドフラワー／ハナイチ）。
- 単位は 百万円・億円・円 を混ぜない。表の中では括弧の率を小さく灰色で。
- 出典・前提は脚注（※）に1行。発表者向けの補足は `notes=` に書き、`notes.md` に出す（スライドには出さない）。

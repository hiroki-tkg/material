# Keynote（.key）から中身を取り出す

Keynote のファイルはアプリが無いと開けないが、中身は zip で、テキストと表は取り出せる。

```bash
pip install python-snappy
python3 -I scripts/keynote_extract.py <file.key> <展開先>
```

出力は「スライドごとの文字列」「表（行×列）」「Data/ の画像一覧」。

## 読み方のコツ
- スライドの順は `Slide.iwa`, `Slide-613-2.iwa`, … の ID 昇順でおおむね合っている。`preview.jpg` は1枚目だけ。
- 各文字列の先頭に1文字ゴミが付くことがある（protobuf の長さバイト）。`'Uイネイブラー事業…'` の `U` は捨てる。
- `出典：…` で始まる文字列は発表者ノート。スライド本文ではなく `notes=` に回す。
- テキストボックスの空行は `Text 5R` のような名前だけ残る。順番の手がかりになる。
- 社名などの ASCII だけの文字列（例: `PAPABUBBLE`, `HAKUBA CRAFT`）は和文フィルタに落ちるので、取りこぼしが疑われるときは
  `re.finditer(rb"[\x20-\x7e]{3,}", blob)` で ASCII も見る。
- 表のセル順は DataList（文字列テーブル）の並び順では分からない（編集順になる）。必ず Tile から復元する。
- 図やグラフが図形で描かれている場合、数値は文字列として取れる（56% / 15% / 29% のように）。

## 画像
- `Data/image-*.png` が貼り付けた画像。`st-*.jpg` はテーマのサムネイルなので無視。
- 複数写真を合成した画像は、写真だけ切り出して（Pillow の crop）並べ直す。
- 外部資料から転載した図（配送フロー等）は Domuz 配色の SVG で描き直す。

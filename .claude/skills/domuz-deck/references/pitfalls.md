# レンダリングで起きた崩れと直し方

確認用 PNG（render.sh が preview/png/ に出す）を必ず見る。LibreOffice の PDF 化では、python-pptx 上の見た目と
文字幅が違うので、頭の中の計算だけでは崩れに気づけない。

| 症状 | 原因 | 直し方 |
|---|---|---|
| 見出しやパネルのタイトルが2行になり、下の凡例やグラフと重なる | 全角28字（15px）を超えた | 語を削る。「購入あり2,542アカウント」→「購入ありアカウント」のように数字は本文に逃がす |
| 要約の根拠が2行に折り返して次の主張と詰まる | 全角47字相当を超えた | `draw_claims` は長い行に64pxを取るが、ページ全体が溢れるなら語を削る。接頭の「広告で獲得する層は」などを落とす |
| 棒グラフの右端の値ラベルが線の値ラベルと重なる | 最終月に棒の値と線の値を両方置いた | 線の値は棒の左側に右寄せで置く（`align=RIGHT` で x を slot 1つ分左に） |
| 折れ線の最初の点の値が軸ラベルに重なる | 線の始点が左端 | 分母が小さい期間は線から外し（`L0=2`）、脚注で断る |
| ハナイチの黄の線が白地で見えない | accent をそのまま線に使った | 線と数字は `T.dark`（HANA_DARK） |
| 章扉の文字が黄地で読めない | 白文字 | ハナイチは `divider_fg=MOSS`（use_theme が設定済み） |
| ウォーターフォールの項目名が棒と重なる | 赤字のとき 0 の線より下に棒が伸びる | 項目名は `yv(min(0, endp))` の下に置く（deck_lib が対応済み）。項目名は「発送\n人件費」のように改行で2行に |
| 横軸ラベルが隣と重なる | 月次を全部書いた | `label_every=3` で四半期ごとにするか、四半期に丸める |
| タイトルとサブタイトルが重なる（表紙） | タイトル2行で高さ不足 | `cover` の既定（y=290、高さ180、2行）に収める。3行にしない |
| 凡例が2行に折れる | 凡例の幅 120 に長いラベル | `legend` は文字数から幅を見積もる。ラベルは全角10字以内 |
| 図形に影が付く | テーマの effectRef | `rect`/`hline` は `_drop_style` で外している。独自に add_shape したら同じ処理を |
| Google スライドで線が消える | コネクタ | 折れ線は `polyline`（freeform）を使う |
| PDF の日本語が別のフォントになる | Zen Kaku Gothic New が未インストール | PDF 化する機械にフォントを入れる。閲覧側は SVG なので不要 |

## 数字の食い違いを防ぐ
- 本文の数字は全部データから f-string で作る。手打ちの数字が1つでもあると、更新のたびにズレる。
- 税込／税抜を混ぜない。受注 CSV の売上は税込なことが多い（÷1.1）。限界利益は税抜のまま。
- 「13 → 34 → 60」のように四捨五入が読み手の期待（12）とずれることがある。期ごとの端数は本文で説明するか、元データの範囲を確認する。
- ブレンドの率（限界利益率 32%）は、大口 41% と広告獲得層 16% の混合といった構造を脚注か別ページで見せる。
